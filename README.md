
# UnMasker

### See Beyond the Surface.

UnMasker is an intelligent website security and threat detection platform designed to help users identify phishing websites, suspicious domains, and potential web security weaknesses.

## Core Capabilities

- **Threat Detection** — URL analysis, suspicious domain detection, and threat intelligence.
- **Web Security Assessment** — HTTPS, security headers, cookies, and configuration analysis.
- **TLS Intelligence** — Certificate validity, hostname matching, and certificate chain inspection.
- **Collaborative Intelligence** — Community-powered website reporting and shared threat intelligence.
- **Unified Risk Assessment** — Explainable security findings and evidence-based risk classification.

## Technology Stack

- React
- Vite
- Tailwind CSS
- Node.js
- Express.js
- MongoDB

## Project Status

🚧 Under active development.

## Security Philosophy

UnMasker aims to provide explainable security assessments based on observable evidence. A valid TLS certificate does not guarantee website trustworthiness, and the absence of detected threats does not guarantee safety.
